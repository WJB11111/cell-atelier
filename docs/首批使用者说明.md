# Cell Atelier · 首批使用者说明

> 发到教师群、教研组、公众号或朋友圈时可以直接取用。三个版本按篇幅排好，二维码图片在 `docs/share/`。

---

## 一、完整版（适合公众号 / 教研组 / 邮件）

**一个能转、能剖、能点选的细胞标本室，七类标本按真实比例摆在一起。**

打开 <https://wjb11111.github.io/cell-atelier/>，你会看到一个可以用鼠标转动的动物细胞。往下有三个别的标本室不常给的东西：

- **并排对比**——把动物细胞和叶肉细胞放进同一个视口、**按同一个真实比例**（20 µm 对 50 µm）。点一次「线粒体」，两个细胞里的线粒体同时高亮、其余结构同时变灰。同一个结构在两种细胞里长什么样、在什么位置，一眼可见。
- **真实尺度**——视口左下角有按比例换算的标尺，拖动缩放时读数自动换挡；页面下方还有一张同尺度图。细胞在屏幕上看着很大，只是因为它被放大了。
- **辨认练习**——出题让你点出指定结构，答错会说明你点到了什么（而不是只说"错了"），最后给出「独立答对 / 借助提示 / 跳过」三项成绩。

给学生的用法很简单：**先并排看两个细胞，再做一道辨认练习，最后看标尺。** 三十秒，屏幕上"细胞很大"的错觉就破了。

七类标本：动物细胞、植物叶肉细胞、蓝细菌、中性粒细胞、有髓神经元、成熟红细胞、人类精子。中文结构笔记写在每个标本右侧，剖面上点任何结构都会显示它的功能与这节课要讲的要点。

**关于离线**：第一次打开后整站会缓存到浏览器里，之后拔网线也能用；浏览器菜单里选「安装」还能装成带图标的桌面应用。教室网络不好也没关系。

**请对学生说明的**：大小是真实的，但形状与数量经过教学简化——叶绿体只画了 6 个（真实 30–50 个），颜色是教学配色而非真实颜色，每个标本没画出来的结构都写在右侧 Field note 里。

有问题或建议欢迎提 issue：<https://github.com/WJB11111/cell-atelier/issues>

## 二、教师群版（中等长度）

分享一个高中生物可用的 3D 细胞标本室：<https://wjb11111.github.io/cell-atelier/>

七类标本（动物 / 叶肉 / 蓝细菌 / 中性粒细胞 / 神经元 / 红细胞 / 精子），中文结构笔记，剖面上点结构就有讲解。三个我觉得课堂上真好用的点：

1. **并排对比**：动物细胞与叶肉细胞按同一真实比例并排，点一个结构两边同时高亮——讲"原核与真核""结构与功能相适应"很直观。
2. **真实尺度**：带标尺和同尺度对比图，专门纠正"细胞在屏幕上看着挺大"的错觉。
3. **辨认练习**：自动出题点结构，答错会说出你点到了什么，末尾给成绩，可以让学生上台做。

第一次打开后整站会缓存，**断网也能用**；也能装成桌面应用。手机、平板都可以。教学简化之处页面上都标明了。

## 配图建议

| 用途 | 用哪张 |
| --- | --- |
| 头图 / 封面 | 并排对比模式截图（`预览` 里的 compare 图），最能说明"它和别的有什么不同" |
| 第二张 | 同尺度图（`SCALE / 真实大小` 那一块），尺寸反差最抓眼 |
| 第三张 | 辨认练习面板，说明它能考人 |
| 二维码 | `docs/share/compare.png`（直接指向并排对比） |

**不要只发首页链接**——首页是一个细胞，深链接才是一个画面：

- 并排对比：`?cell=animal-cell&compare=plant-cell`
- 辨认练习：`?cell=animal-cell&practice=1`
- 真实尺度：`?cell=plant-cell#size-chart`
- 植物完整外壳：`?cell=plant-cell&view=whole`
